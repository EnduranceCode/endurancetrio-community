# EnduranceTrio Community - Release v0.3.8

This patch release ships a patched OpenJDK runtime addressing CVE-2026-114938 (Java4Shell) and adds maintainer skills for backlog drafting and publishing.

## Breaking Changes

None.

## Features and Enhancements

None.

## Bug Fixes

### Critical & Production Fixes

- **Java runtime (CVE-2026-114938 / Java4Shell)** — the application runs on OpenJDK 21; rebuild or redeploy the Docker image so it pulls the patched `eclipse-temurin:21-jre-alpine` base image that fixes the heap-based buffer overflow in the AVX-512 Base64 decoder. No application code change is required.

## Performance & Optimizations

None.

## Refactoring & Technical Debt

- **Backlog drafting skill** — added `draft-backlog-item` to turn Inbox planning issues into validated local backlog-item drafts through a refinement interview and bundled checker.
- **Backlog publishing skill** — added `publish-backlog-draft` to publish approved drafts to planning issues and move them to Backlog (dry-run by default, with `--apply` to execute).

## Documentation

- **Planning workflow** — documented backlog drafting and publishing in `docs/development.md` and `AGENTS.md`.

## Dependency Updates

None.

---

**Deployment**: the Docker image for this release is published as `ghcr.io/endurancetrio/endurancetrio-community:0.3.8`. Set `PRD_VERSION=0.3.8` in the deployment `.env`.
