# EnduranceTrio Community - Release v0.3.3

This release adds dynamic, localized SEO metadata and JSON-LD structured data to public pages, and introduces navigation, filtering, and search to the athletes directory. The athlete directory is now browsable through windowed pagination, an alphabetical first-letter index, and a free-text name search, with all navigation state preserved across language switches.

## Breaking Changes

- **PostgreSQL `pg_trgm` extension required for existing deployments.** The athlete directory search migration creates `pg_trgm`-backed GIN indexes. Fresh databases receive the extension automatically from `init-db.sh`, but **existing databases are not re-initialized**, so the extension must be enabled once before deploying this version, or Flyway will fail and roll back:
  ```shell
  docker compose -p endurancetrio-community exec postgres psql \
    --username postgres --dbname prd_endurancetrio_community \
    --command 'CREATE EXTENSION IF NOT EXISTS pg_trgm WITH SCHEMA endurancetrio_hub;'
  ```
  See `docs/deployment.md` → *Enabling `pg_trgm` on an existing deployment*. New deployments are unaffected.

## Features and Enhancements

### API & User Facing Changes

- **Dynamic SEO metadata** — public page `<head>` titles and descriptions are now built from real page data (athlete names, event titles, years, cities) and localized in English and Portuguese, replacing the previous generic static copy.
- **Article JSON-LD** — insight detail pages emit `schema.org/Article` structured data, serialized server-side by `JsonLdUtils` and rendered as an `application/ld+json` script in the shared head fragment.
- **Windowed numbered pagination** — the athletes directory now renders a bounded page-link control (with ellipsis markers) so the listing stays navigable as the athlete count grows.
- **Alphabetical letter-range filter** — a first-letter index (`A–F`, `G–L`, …) lets visitors browse athletes by initial; ranges with no results are hidden, and the active range is highlighted.
- **Name search** — a free-text search box filters the directory by athlete name (case-insensitive).
- **Language-aware URL state** — the language swap now preserves the active filter, search term, and page number when switching between English and Portuguese, using `UriComponentsBuilder` instead of string-replaced URLs.
- New search/chevron icon added to the endurance icon set.

### Core Logic & Business Rules

- New `AthleteLetterRange` enum and `LetterRangeAvailabilityDTO` back the first-letter index.
- `AthleteRepository` gains a letter-range count projection (`AthleteFirstLetterCount`) so the UI only shows populated ranges, and applies case-insensitive filtering for the combined search/letter-range query.
- `AthleteFilterDTO` captures the search term and letter range; `AthleteServiceMain` orchestrates the combined query and pagination window.
- New Flyway migrations add athlete-directory indexes (`V20260823.001`) and run minor data housekeeping (`V20260823.002`) for both H2 and PostgreSQL.
- `JsonLdUtils` serializes insight structured data server-side, with fallbacks for unknown publish dates and missing images.

- Dedicated database indexes (including PostgreSQL `pg_trgm` GIN indexes) added for the athlete-directory filter and pagination queries.

- New `PageWindow` model and `PaginationUtils` centralize windowed pagination calculation.
- `PageMetadataUtils` extended with `JsonLdUtils` (`PageMetadata.jsonLd`) and language-aware, parameter-preserving URL building.
- `init-db.sh` and `docs/deployment.md` updated for the `pg_trgm` prerequisite and data housekeeping step.

## Documentation
