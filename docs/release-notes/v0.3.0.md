# EnduranceTrio Community - Release v0.3.0

This is the first public release of **EnduranceTrio**, a web platform and REST API for endurance sports data and resources. It combines a public-facing website with a structured database of Portuguese triathlon and multisport events, historical results, athletes, and insights, alongside a secure, documented API for tracker-domain functionality.

## Breaking Changes

None — this is the initial release.

## Features and Enhancements

### API & User Facing Changes

- **Public website** with internationalization in English and Portuguese (`/en`, `/pt`), including a language selector.
- **Dynamic home page**, mission page, and an insights/articles section with event-scoped articles and author profiles.
- **Historical events browser**: year-based event listing, per-event overview pages, and race result pages with individual-results tables, sorting, and result-status indicators, plus prev/next race navigation.
- **Athletes directory**: listing page and athlete profiles with race history and authored articles.
- **Tracker REST API** (integrated): IoT telemetry ingestion, historical telemetry retrieval, and GeoJSON route management, secured by dual-header authentication (`ET-Owner` + `Authorization: Bearer`), with interactive **Swagger UI** documentation.
- **Newsletter subscription** (Kit.com) with success, confirmation, and error flows.
- **Privacy and cookies policies**, Ko-fi donation button, footer with app version and copyright.
- **SEO**: sitemap.xml and robots.txt endpoints, hreflang language variants, and Open Graph metadata.
- **Custom error pages** (403/404/500) with debug modal.

### Core Logic & Business Rules

- Domain model for events, courses, races, results, competitors, athletes, and insights with JPA entities, converters, and repositories.
- Flyway-managed database schema for PostgreSQL (and H2 in test mode) with ICU root collation and UTC timezone enforcement.
- Historical dataset of Portuguese triathlon events (1984-1989) including Portugal's inaugural triathlon results (1984 Peniche).
- Caffeine caching for race results and event overview.
- Initial account provisioning via `FIRST_OWNER`/`FIRST_HASH` environment variables with bcrypt (cost 12) API-key hashing.

### Critical & Production Fixes

- None — first release.

### General Fixes

- Locale resolution on error pages and language-switch flicker.

- JavaScript sort-mutation and `isNaN` handling in table sorting.

## Performance & Optimizations

- Caffeine caching for race results and event overview.
- Production frontend bundle: minified assets, no source maps, raster image optimization.
- JVM G1GC tuning and UTC default timezone in production container.

## Refactoring & Technical Debt

- Domain-driven package reorganization across data/business/app modules.
- Server-side event pages replacing client-side tabs.
- Icon system refactored to SVG `mask-image` CSS classes.
- SonarQube Cloud integration with CPD and analysis exclusions.
