# EnduranceTrio Community - Release v0.3.4

This release completes the first semester of 1987 in the historical dataset of Portuguese triathlon events, adding race results for six 1987 races. It also extends the age-group taxonomy with a new category, orders race-results age-group tables by their natural category order, and keeps private historical-data staging files out of the packaged artifacts and static analysis.

## Breaking Changes

None.

## Features and Enhancements

### API & User Facing Changes

- **Deterministic age-group ordering on race results pages** — individual results are now grouped by age category consistently, with the overall/open category (`OPEN`) always shown first, followed by the remaining categories in their declaration order (e.g. `F1`, `F2`, …, `G`, `M1`, …), regardless of the order in which results were ingested.
- **New age category** — the `AgeGroup` enum gains category `G`, used to label 1987 race results.

### Core Logic & Business Rules

- Historical race results for the event ID 9 1987 triathlon: athlete records and race results.
- Historical race results for the event ID 10 1987 triathlon: athlete nationality data and race results.
- Historical race results for the event ID 11 1987 triathlon: athlete records and race results.
- Historical race results for the event ID 13 1987 triathlon: athlete record enrichment and race results.
- Historical race results for the event ID 14 1987 triathlon: athlete records and race results.
- Historical race results for the event ID 15 1987 triathlon: athlete record enrichment and race results.
- Historical race results for the event ID 16 1987 triathlon: athlete record enrichment and race results.
- Together, the event ID 9–16 races complete the historical coverage of the **1987 first semester** of Portuguese triathlon racing.

## Refactoring & Technical Debt

- Race results are reordered by `AgeGroup` ordinal (with `OPEN` first) in `RaceServiceMain` via a new `orderByAgeGroupOrdinal` helper; the results map is now built as a `LinkedHashMap` so grouping order is stable.
- Private historical-data staging files (`db/data-staging/**`) are now excluded from the packaged `endurancetrio-data` resources and from SonarQube analysis, keeping pre-processing data out of jars and static analysis.

## Documentation

- `DATABASE.md` updated with entries for the new race-results migrations (`V20260824.001`–`V20260828.001`).
- `docs/development.md` version-tagging instructions updated (`git push origin ...` for tags).
