# EnduranceTrio Community - Release v0.3.5

This release adds a configurable **Featured Events** section to the homepage, spotlighting the São Martinho do Porto Triathlon alongside a companion bilingual insight article. It also adds support for recording one-off relay competitors and their member athletes, allows team results without an official rank, and keeps team race types out of the home results feed.

## Breaking Changes

None.

## Features and Enhancements

### API & User Facing Changes

- **Featured Events homepage section** — a new section renders a featured insight-article card next to a list of featured events (ordered by start date descending, with sport codes and location details), configurable via the `FEATURED_EVENT_IDS` and `FEATURED_EVENT_ARTICLE_ID` environment variables.
- **São Martinho do Porto Triathlon insight article** — new bilingual (PT/EN) insight article by Ricardo Santos telling the story of the race's four editions, linked to the four TSMP event pages, with gallery images ("The Bay of Dreams").

### Core Logic & Business Rules

- **One-off relay competitors** — new `relay_entry` and `relay_entry_athlete` tables (migration `V20260830.001`) and a `RelayEntry` entity model a relay entry on a race result table: a group of athletes entering a specific race who, unlike a club, have no enduring roster. Each contributing athlete is recorded alongside the per-race gender category and age group.
- **Nullable team-result rank** — the `team_result.rank` column no longer requires a value (migration `V20260829.001`), so relay teams without an official placement can be recorded.
- **Featured events lookup** — `EventService#getEventsByIds` fetches events by ID with their courses eagerly loaded, ordered by start date descending.
- **Team races excluded from the home feed** — the homepage "Latest Results" section now excludes team race types (`TEAM_BY_RANK`, `TEAM_BY_TIME`, `TEAM_BY_POINTS`, `TEAM_RELAY_PARENT`, `MIXED_RELAY_PARENT`).
- **Data-quality migration** — `V20260918.001` corrects the long name of an existing athlete record (ID 177).

- `Team` is extended as the base for `RelayEntry`, carrying gender category, age group, and the set of contributing athletes; `TeamMapper` fixtures updated accordingly.
