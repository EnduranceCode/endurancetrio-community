# EnduranceTrio Community - Release v0.3.1

This patch release expands the historical dataset of Portuguese triathlon events with race results for two 1985 races and adds an English translation of Paulo Cavaleiro's insight article on the origins of triathlon in Portugal.

## Breaking Changes

None.

## Features and Enhancements

### API & User Facing Changes

- **English translation** of Paulo Cavaleiro's insight article "Beyond Peniche: How Triathlon Began in Portugal", with updated Portuguese article text.

### Core Logic & Business Rules

- Historical race results for the **1985 Cascais International Triathlon** (event ID 2): athlete records, race results, and result-status data.
- Historical race results for the **1985 Peniche Triathlon** (event ID 3): athlete records, race results, and result-status data.
