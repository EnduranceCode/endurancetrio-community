# EnduranceTrio Community - Release v0.3.2

This patch release expands the historical dataset of Portuguese triathlon events with race results for four 1986 races and displays the team name recorded on each result in the individual results tables.

## Breaking Changes

None.

## Features and Enhancements

### API & User Facing Changes

- **Team name display** — individual results tables now show the team name recorded on each result instead of the linked team's short name.

### Core Logic & Business Rules

- Historical race results for the **1986 Setúbal UNICEF Triathlon** (event ID 4): athlete records and race results.
- Historical race results for the **1986 Cascais Triathlon** (event ID 5): athlete records, team records, and race results.
- Historical race results for the **1986 Espinho Triathlon** (event ID 6): athlete records and race results.
- Historical race results for the **1986 Tancos Triathlon** (event ID 8): athlete records and race results.

## Bug Fixes

### General Fixes

- Age group and para class columns narrowed in the individual results table.
- Results tab activation fixed via `bulma-tab` initialization on page load.

## Performance & Optimizations

None.

## Refactoring & Technical Debt

- `IndividualResultDTO` carries a dedicated `teamName` field; `TeamMapper.map(Team)` reduced back to a single-argument signature.

## Documentation

- `DATABASE.md` updated with entries for the four new race-results migrations.

## Dependency Updates

None.

---

**Deployment**: the Docker image for this release is published as `ghcr.io/endurancetrio/endurancetrio-community:0.3.2`. Set `PRD_VERSION=0.3.2` in the deployment `.env`.
